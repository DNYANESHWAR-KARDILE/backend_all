1. Validation
User ne jo data diya hai, wo sahi format me hai ya nahi check karta hai.
Example: Email me @ hai ya nahi.
Password kam se kam 8 characters ka hai ya nahi.
Validation = Data sahi hai?

2. Verification
Di gayi information actually true hai ya nahi confirm karta hai.
Example: Email par OTP bhejkar check karna.
Sahi OTP dala → Email verified.
Verification = Ye sach/genuine hai?


3. Authentication
System check karta hai ki user kaun hai.
Example: Email + Password se login karna.
Correct credentials → User identify ho gaya.
Authentication = Tum kaun ho?


4. Authorization
Login ke baad check karta hai ki user ko kya karne ki permission hai.
Example: Customer product buy kar sakta hai.
Lekin product delete sirf Admin kar sakta hai.
Authorization = Tum kya kar sakte ho?
